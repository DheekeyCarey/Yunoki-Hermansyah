Scan Lembar Jawaban Ujian (LJK)

Buat LJK, Scan LJK Pilih nama siswa dari "Siswa yang sedang discan" pastikan ke-4 kotak hitam di sudut kertas terlihat jelas. Kalau hasil suatu siswa dirasa kurang tepat, tekan Scan Ulang. Setelah selesai scan, lanjutkan ke tab Riwayat Scan untuk melengkapi nilai Esai/Isian lalu menyimpannya ke Data Nilai.

Seksi B (Essay) & C (Isian) adalah ruang jawaban tulis tangan siswa dan tidak diperiksa oleh kamera saat Scan.

Ikut tersinkron dengan tab Buat LJK.
